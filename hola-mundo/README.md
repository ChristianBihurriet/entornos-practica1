# Hola Mundo

Proyecto Java sencillo para aprender el proceso básico de escribir, compilar y ejecutar un programa.

## Requisito

- JDK 21

## Compilar y ejecutar

Desde una terminal, entra en la carpeta del proyecto:

```bash
cd hola-mundo
```

Compila el programa:

```bash
javac HolaMundo.java
```

Ejecuta el programa:

```bash
java HolaMundo
```

## Archivos `.java` y `.class`

Un archivo `.java` contiene el código fuente que escribimos. Al compilarlo, Java genera un archivo `.class` con el código que puede ejecutar la máquina virtual de Java.
